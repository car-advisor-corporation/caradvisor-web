Conectar con GitHub

Para publicar los cambios en la web hace falta un token de acceso de GitHub. Se guarda solo en este navegador y nunca sale de él salvo para hablar con GitHub.

  1. Abre github.com/settings/personal-access-tokens/new
  2. En Repository access elige Only select repositories → caradvisor-web
  3. En Permissions → Repository permissions pon Contents: Read and write
  4. Genera el token y pégalo aquí abajo
Dale permiso solo a este repositorio. Con ese token se puede cambiar la web, así que no lo compartas por chat ni por correo.
